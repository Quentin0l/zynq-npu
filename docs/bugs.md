# Journal des bugs

Pour chaque bug qui a coûté plus d'une heure : le symptôme, la fausse piste, la vraie cause. Le plus coûteux deviendra une histoire à raconter en entretien.

## Modèle

### AAAA-MM-JJ · titre court

- **Symptôme** : ce qu'on voyait.
- **Fausse piste** : ce qu'on a cru d'abord, et pourquoi.
- **Vraie cause** : ce qui se passait vraiment.
- **Correctif** : le commit.
- **Ce que j'en retiens** : la règle ou le test qui l'aurait attrapé plus tôt.
